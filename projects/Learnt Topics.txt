-------------------------------------------------- DAY 1 ----------------------------------------------------------


1. Ollama
Ollama lets us run AI models on our own computer.
It works locally.
Example models: Llama, Qwen, Gemma.

Remember:
👉 Ollama = Run AI locally

2. OpenAI
OpenAI provides powerful AI models like GPT.
We can use them through the OpenAI API.
Our application sends a request → OpenAI processes it → we get a response.

Remember:
👉 OpenAI API = Use AI through code

3. System Prompt
Tells the AI how to behave.
It contains rules or instructions.

Example:

"You are a helpful teacher."

Remember:
👉 System = How AI should behave

4. User Prompt
Tells the AI what the user wants.

Example:

"Explain Python loops."

Remember:
👉 User = What AI should do

5. Summarization
Summarization means making long information short.
We keep only the important points.

Examples:

Shorten an email
Summarize a meeting
Summarize a document

Remember:
👉 Summarization = Long → Short + Important information
